🚀 Como atualizar o site

  1. Edite os produtos abaixo — a tabela de cartões de visita já vem carregada
  2. Clique em "💾 Exportar DB" — salva um johen_cartoes_db.json com todos os produtos
  3. Da próxima vez que abrir o admin, clique em "📂 Importar DB" e selecione o arquivo salvo
  4. Clique em "⬇️ Gerar catalogo.html" → o arquivo baixa automaticamente
  5. GitHub → cria/edita cartoes.html (ou index.html da linha) → cola o conteúdo → Commit

☁️ Sincronização com GitHub Não conectado

Depois de conectar, toda vez que você salvar, editar ou excluir um cartão, ele é enviado automaticamente pro arquivo db-cartoes.json no repositório catalogo — assim os dados ficam disponíveis em qualquer aparelho.
Não tem o token ainda? No GitHub (Safari): toque no seu perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → em "Repository access" escolha só o repositório catalogo → em "Permissions" ative Contents: Read and write → gera e copia o token pra cá.
